# Typographie

Notes de lecture, à garder sous la main pour les maquettes.

> La typographie est l'aspect visuel du langage écrit.
> — Matthew Butterick

## Règles de base

1. Corps du texte : 15 à 25 px à l'écran
2. Longueur de ligne : 45 à 90 caractères
3. Interlignage : 120 à 145 % du corps
4. Pas plus de deux familles par site

## En français

- Une espace insécable avant `: ; ! ?` et dans les guillemets « comme ceci »
- Les majuscules accentuées : *À*, *É*, *Ç*
- Les nombres : 1 000 €, pas 1,000 €

Utile pour le [[Cahier des charges]] et pour [[Identité Vélo Rouge]]. D'autres liens dans la vue « Liens ».
